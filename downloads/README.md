# Download: Manhattan Building Kit (everything in one zip)

`manhattan_building_kit.zip` is 190 MB, so it's stored here in 5 parts (GitHub's limit is 100 MB per file).

1. Download all 5 `manhattan_building_kit.zip.partNN` files and the join script for your system into one folder.
2. Join them:
   - **Windows:** double-click `join_windows.bat`
   - **macOS / Linux:** `sh join_mac_linux.sh`
3. Unzip `manhattan_building_kit.zip`.

SHA-256 of the joined zip: see `manhattan_building_kit.zip.sha256`.

**Contents:** the 100-building kit (GLB, previews, `.blend`), the 30-building HD kit (glTF with LOD0/LOD1,
shared PBR textures, `manhattan_hd_kit.blend`, renders) and all generator source code.
